# Changelog

## 1.0.1

- The panel now uses Drawdy's own colours and font, with a more compact header so more emoji fit
- Group chips scroll with a fade at the edge, and selected options are grey instead of lime
- Skin tones sit beside the Label option, and the search box has a glyph

## 1.0.0

First public release

- About 1,600 Microsoft Fluent emoji in eight groups, with search by name or meaning (party, love, lol)
- Shaded and Flat styles, five skin tones for people and hands, four sizes and an optional name label
- Drag an emoji onto the board or click to add it in view; repeated clicks line up in rows
